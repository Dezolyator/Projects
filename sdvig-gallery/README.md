# Сдвиг

«Материя тишины» — интерактивная выставка онлайн-галереи современного искусства «Сдвиг». В коллекции девять работ с названиями, описаниями и сведениями о материале.


## Функции

- Поиск по названию, имени автора, материалу и году. Поиск сочетается с фильтром по виду искусства и учитывает варианты написания с «е» и «ё».
- Карточки с крупным изображением и описанием работы. Модальное окно поддерживает клавишу Escape и возвращает фокус на открывший его элемент.
- Избранное с сохранением через `localStorage`. Для списка избранного также доступны поиск и фильтры.
- Адаптивная вёрстка, изображения WebP и отложенная загрузка изображений каталога.

## Код и изображения

- `src/App.jsx` — страницы выставки и состояние каталога.
- `src/Artwork.jsx` — компоненты карточки и модального окна.
- `src/useFavorites.js` — сохранение избранного.
- `src/artworks.js` — содержимое выставки.
- `public/art/` — обложка и девять изображений коллекции в формате WebP.
